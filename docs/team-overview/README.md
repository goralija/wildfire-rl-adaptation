# Pregled za tim

[`budzetski-rl.html`](budzetski-rl.html) je kopija stranice objavljene kao privatni Claude
artifact (https://claude.ai/artifact/EFi7EXKkvehgTt1GYtoi5Q, verzija 8, 2026-11-12). Stranica
objašnjava projekat čitaocu koji ga ne poznaje: MDP, podatke, kod, gate, hronologiju, grešku
ADR-029, ispravke, rezultate faza 1 i 2, pregled nakon faze 2 i kako nastaviti, s dijagramima
i grafikonima. Sadržaj prati repozitorij; kad se razilaze, važi repozitorij.

- **Otvaranje:** fajl se otvara direktno u pregledniku. Fontovi dolaze s Google Fonts, pa bez
  interneta stranica koristi rezervne fontove.
- **Ažuriranje:** izmijeni ovaj fajl, objavi ga kao artifact na isti link (Claude Artifact alat,
  `url` iznad; prvo pročitati živu verziju preko linka), pa commituj kopiju ovdje. Artifact je
  privatan; Harun ga dijeli kroz meni Share.
- **Brojke** na stranici su iz ADR-031, ADR-032, njihovih izvještaja u `reports/real-fire-data/` i
  iz [pregleda 2026-11-11](../research/review-2026-11-11/SUMMARY.md). Simulatorski rezultati nisu
  dokaz o stvarnom gašenju.
