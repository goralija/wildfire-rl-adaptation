# Tokovi rada

Nova sesija: STATUS -> NEXT_SESSION -> odluke/protokol -> git status -> testovi -> prvi otvoreni task.
Novo istraživanje: primarni izvor -> sažetak sa datumom -> uticaj na odluku -> ADR ako mijenja pravac.
Novi podatak: URL/licenca -> hash -> validacija -> manifest -> split -> tek onda trening.
Eksperiment: zamrznut config -> testovi -> procjena troška -> novi run ID -> manifest ->
raw epizode -> uparene statistike -> graf -> experiment log -> interpretacija i ograničenja.
Promjena ponašanja: test koji prvo pada -> mala implementacija -> suite -> log/status.
Objava: pregled privatnosti/licenci i veličine artefakata -> korisnikov nalog za remote
promjenu -> push odgovarajuće grane; ne gurati main automatski.
Open Questions: timski proces reviewa i odobrenja konačnog protokola.
