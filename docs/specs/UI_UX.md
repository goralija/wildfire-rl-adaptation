# Istraživački interfejs i vizualizacije

Sadašnji interfejs je CLI i Markdown. Nema potrebe za dashboardom u ovoj fazi.
Korisnik bira config i novi output folder; dobija reproducibilne CSV/JSON/SVG artefakte.
Graf mora navesti backend, da je synthetic pilot, osu budžeta i udio opožarenog,
politike i šta znače intervali. Označiti truncation i n u pratećoj tabeli.

Planirani demo: identične mape i legenda za FUEL/FIRE/BURNED/TREATED/NONFUEL,
priority overlay, vrijeme i B/remaining. Jednake boje i skale kroz sve politike.
Izbjegavati samo crveno/zeleno razlikovanje; koristiti legendu/oblike i opise.
Ne ulagati u UI prije simulator gatea i glavne evaluacije.
Open Questions: konačni format postera/demonstracije, pristupačnost izabranog medija.
