# Smjernice za buduće sesije

Pravila rada su u root `AGENTS.md`. Izvor istine: potvrđeni zahtjevi -> ovaj spec ->
protokol -> plan; ne prepisivati potvrđene zahtjeve pretpostavkama.
Status i odluke su radna memorija. Svaka sesija upiše šta je promijenila, komande,
rezultate i prvi sljedeći korak. Ne oslanjati se na chat historiju ili instalirani .venv.

Kad činjenica nije provjerena, napiši planirano/neprovjereno. Ne obećavaj RL poboljšanje.
Svaki značajan novi paket zahtijeva razlog i zabilježenu verziju. Čuvaj mali core.
Ne graditi UI, generičke backende ili cloud infrastrukturu bez potrebe istraživanja.
Open Questions: nema dodatnih obaveznih pitanja za bootstrap; korisnik je tražio autonomiju.
